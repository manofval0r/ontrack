## 🛠 Tech Stack Overview

- **Frontend**: React, TypeScript, Tailwind CSS, Vite
- **Backend**: Django REST Framework, Supabase (PostgreSQL), Render
- **AI & Speech**: NVIDIA Nemotron, TTS / ASR audio processing
