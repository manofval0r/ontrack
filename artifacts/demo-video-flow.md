# OnTrack Demo Video — User Flow (≈2.5 minutes)

Device prep: fresh preview build installed, test account created, Wi-Fi on,
Do-Not-Disturb on, screen brightness full, Expo Go/dev banners dismissed.
Narration is calm and concrete — say numbers, not adjectives.

## Scene 1 — Splash → Onboarding (0:00–0:20)
Cold-launch the app. Splash mark → swipe through the 3 onboarding phones
(coach intro → tracker builds itself → goal draft preview). Line: "OnTrack
turns plain words into trackers — no forms, no setup."

## Scene 2 — Sign up (0:20–0:40)
Tap "Continue with GitHub" (brand button, one tap) → approve → land on Home.
Point out: "One tap, my work identity is already attached for later."

## Scene 3 — Chat creates a goal (0:40–1:10) — THE HERO
Open Chat (center +). Say/type: "I want to close 5 enterprise deals this
week." Show the proposal card (counter tracker, target 5) → "Use this
tracker." Then: "Did 1 more viewing today" → progress ticks to 4 of 5.
Line: "I talk, it tracks. Every check-in is one sentence."

## Scene 4 — Home goal cards (1:10–1:30)
Back to Home. Greeting + streak flame, Today's Focus card, active goal cards
with animated progress bars. Tap a card → goal detail (streak stats, week
activity strip, checklist) → Check in → back.

## Scene 5 — Work-block (1:30–1:50)
From goal detail, "Work-block" → 25:00 timer overlay. "When it's time to
work, everything else waits." Dismiss via Keep working.

## Scene 6 — Integrations (1:50–2:10)
Settings → Integrations → GitHub Connected → Manage → detail screen (repo,
streak, activity). "Commits verify themselves against my checklist goals."
Mention Google Calendar connected the same way.

## Scene 7 — Voice + App updates close (2:10–2:30)
Chat composer → mic button → dictate a check-in (editable before send).
Then Settings → App updates → "Check for app updates" → Up-to-date.
Close: "OnTrack. Say your goal. Get your tracker."

## Do NOT show
- Expo Go reload shakes, Metro banners, or the login screen twice.
- The Supabase allowlist error state (fix before filming).
- Typing passwords on camera — use the GitHub social path (Scene 2).
- Real customer repos or emails — test account only.
